# 🎨 Real-Time Colour Detection

## 📌 Overview
Real-Time Colour Detection is a computer vision project that detects and identifies colours from a live webcam feed. Using Python and OpenCV, the application processes video frames in real time and displays the detected colour name along with its RGB values.

## 🚀 Features
- Real-time colour detection using a webcam.
- Identifies different colours from live video.
- Displays the detected colour name.
- Shows RGB colour values.
- Uses OpenCV for image processing.
- Simple and user-friendly interface.

## 🛠️ Technologies Used
- **Python** – Programming language.
- **OpenCV** – Image processing and computer vision.
- **NumPy** – Numerical operations and array processing.

## ⚙️ Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/RealTime-Colour-Detection.git
```

### 2. Navigate to the Project Directory
```bash
cd RealTime-Colour-Detection
```

### 3. Install Required Libraries
```bash
pip install -r requirements.txt
```

Alternatively:
```bash
pip install opencv-python numpy
```

### 4. Run the Application
```bash
python colour_detection.py
```

## 💻 How It Works
1. The webcam captures live video.
2. OpenCV processes each video frame.
3. The application analyzes the colour information.
4. The detected colour is identified.
5. The colour name and RGB values are displayed on the screen.
